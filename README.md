# 小飞机识字 · 每天十个字

500 高频字识字应用，蜡笔图画板风格。周一到周五每天 10 个新字，周六周日复习，念错的进修理站。

## 怎么跑

```
cd "/Users/hema/claude code/航母工地"
python3 -m http.server 8899
```

浏览器打开 http://localhost:8899

**必须走 localhost，不能直接双击 index.html** —— 浏览器只在 localhost 或 https 下才给麦克风权限。

调试：地址加 `?d=6` 强制成周六（`d=1..7`）；加 `?night=1` / `?day=1` 强制昼夜。

## 玩法

**一个字 = 战斗机的一个零件**

字卡出来 → 先念这个字怎么念，再组词 → 孩子跟着念 → 语音识别自动判对错。

**一轮十个字，每个字只出现一次。** 念对了进下一个；没念对（或点「不认识」）就把这个字放进修理站，
同样进下一个 —— 不会在这一轮里反复纠缠同一个字。十个字走完就算打卡完成，
想再练就点「再学一遍这十个字」。

不管念对没念对，蜡笔都会画出一个零件，顺序是：机身 → 机头 → 座舱 → 机翼 → 尾翼 → 平尾 →
后轮 → 前轮 → **导弹** → 引擎火焰。所以每天都能画出一架完整的战斗机。
顶部十格进度条会区分：念对的格子是彩色，没念对的是粉色。

**当天可以反复练**

十个字过完一遍后，出现「再学一遍这十个字」—— 同样十个字打乱重来，想巩固几遍就几遍。
每练完一遍，甲板上那架飞机加一颗星（最多三颗）。重复练不会多发飞机，也不会消耗新字库。
500 字全部学完之后，平日自动转成复习模式，不会发空课。

**一天 = 一架飞机，一周 = 一艘航母**

甲板七个停机位，对应周一到周日。每天打卡完成，飞机滑上对应位置。
甲板本身就是打卡表 —— 空位就是没打卡的那天。
七个位置全停满 = 满编出航，这艘航母进「我的舰队」，下周一新的一艘入港。

**降落长镜头（6 秒，每练完一遍都放一次）**

| 时间 | 画面 |
|---|---|
| 0–0.6 秒 | 全景，飞机从右上方远处进场 |
| 0.6–1.2 秒 | 镜头推近跟拍，飞机变大 |
| 1.2–3.6 秒 | 特写下滑，机头略低，轮子空转，尾焰燃烧 |
| 3.6 秒 | 抬头拉平触地，轮胎猛转，扬起白烟 |
| 3.6–5.4 秒 | 甲板上滑行，轮子渐慢 |
| 5.4–6.0 秒 | 镜头拉回全景，飞机停稳在当天的停机位 |

飞机从舰尾（舰岛那一侧）进场，机头朝着飞行方向 —— 甲板上的飞机都是机头朝左停放的。

第一遍是新飞机出厂降落；第二遍起是同一架「巡逻回来」再降落一次，落地加一颗星。
音效跟画面分段对齐：引擎由远及近的扫频、轮胎触地、滑行摩擦、停稳提示音，全部现场合成，
不依赖音频文件。

**每架飞机机型都不一样**

5 种机型，机身轮廓完全不同：

| 机型 | 特征 |
|---|---|
| 截击机 | 修长机身，三角翼 |
| 重型攻击机 | 粗壮机身，圆钝机头，平直机翼 |
| 双垂尾机 | 两片垂直尾翼，细长机头 |
| 前掠翼机 | 机翼向前掠，高瘦尾翼 |
| 鸭翼机 | 机头前多一对小鸭翼，大三角翼 |

机型每天换，配色（6 种军绿）每天换，花纹（素色/条纹/迷彩/飘带）两天换一次，
再叠导弹数和鲨鱼嘴涂装。**前 70 天外观零重复。**
引擎尾焰快速跳动，导弹尾焰慢慢烧。

**明天来的战斗机**

侧栏常驻一个预告面板，画出明天那架的样子并写出名字（比如「墨绿迷彩鸭翼机 · 鲨鱼嘴 · 双导弹」），
给孩子一个明天再来的理由。

**学过的字 · 按天定向复习**

侧栏有一个「学过的字」面板，按周一到周日列出每天学的那 10 个字，可以往前翻周。
点某一天的「复习」，就把那天的十个字打乱重来一遍 —— 念完之后，**那天的战斗机会重新降落一次**，
并给那天加一颗星（最多三颗，星星显示在甲板上那架飞机头顶）。

定向复习只更新掌握程度和修理站，不会算进今天那一课的进度。今天还没学完的那一行显示「学习中」，
不提供复习按钮。

**满编出航**

周一到周日七天全部打卡完成 → 第七架降落之后，**整艘航母带着七架战斗机往左开走**，
配两声汽笛和破浪声。天空、月亮、海面留在原地，只有船和飞机移动。
之后甲板下方会常驻一个「再看一次航母出航」按钮，随时可以重放。

**昼夜天空**

白天（6:00–18:00）是蓝天、太阳、三朵会缓缓飘动的白云；
晚上是深蓝夜空、带环形山的月亮、十五颗一闪一闪的星星，海面和面板底色也跟着变深。
调试时地址加 `?night=1` 或 `?day=1` 可以强制切换。

**修理站：只进不出，永久保留**

点「不认识」「还不会」，或者语音判定没通过 → 这个字进修理站，**直接换下一个，这一轮不再出现**。

**进去之后就再也不会出来。** 念对了只是标成绿色打勾（表示已经会了），字还留在站里 ——
包括跨周、跨月，都不会清空。这是刻意的：不会的字要能一直反复复习，
不能因为某天念对一次就永远消失。

修理站**按进站日期分组显示**（8/28 周五、8/29 周六…），面板标题写着一共攒了多少字，
超过 8 天的会折叠成一行提示，但周末照样会抽到。

**周末复习怎么从修理站挑字**

字攒多了（比如 10 周下来上百个），不能老抽同样那十个。规则是：

1. **还没念对过的排最前**（打乱顺序）
2. 再从**已经念对过的**里面随机补齐
3. 不够 10 个才从别的学过的字里补（曾错过的权重 ×3）

这样每个进过修理站的字都轮得到。当天学完点「去修理站」也是按同一套规则抽 10 个来练。

**两种判定模式，随时切换**

按钮下方有一个开关：

- **自己念给它听**（默认）：孩子按「跟着念」，浏览器语音识别自动判对错
- **妈妈判定**：屏幕上只有「念对了 / 还不会」两个大按钮，你听完自己点

选择会记住。环境吵、连续两次识别不到时也会自动切到妈妈判定兜底。

## 文件

| 文件 | 职责 |
|---|---|
| `js/data.js` | 500 字库，`字\|例词\|场景句` |
| `js/state.js` | 状态与 localStorage、日期/周计算 |

| `js/ui.js` | 渲染与交互 |

## 改了代码后页面没变化？

`index.html` 里所有 css/js 都带 `?v=N`，改完代码把这个数字加一。
页面头部还加了 no-cache 声明，正常情况下直接刷新就能看到新版本。
要是还不对，浏览器里 Cmd+Shift+R 强制刷新。

## 配色

背景纯白，飞机军绿、航母军绿不变。其余用一套马卡龙色：

- 顶部十格进度条，念对一个亮一格，十格十种颜色
- 星期一到日各有专属颜色，日期牌和甲板下的星期标签用同一套色
- 明天预告面板薄荷绿、修理站淡粉、我的舰队淡紫、画板天蓝
